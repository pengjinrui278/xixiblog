> **本篇范围**：第 21-23 章——图算法的"三巨头"。三条主线：**最小生成树**（贪心 + 割性质）、**单源最短路**（松弛框架 + 三种算法的排序/分层策略）、**全源最短路**（两种 DP + 重加权 trick）。这三个问题是算法面试与考试重合度最高的图论内容。

## 一、最小生成树：切与轻边（§21.1）

### 问题与 GENERIC-MST

连通无向带权图 $G=(V,E)$，找无环边集 $T \subseteq E$ 连通全图且 $\sum w$ 最小（恰 $|V|-1$ 条边）。

```
GENERIC-MST(G, w)
 1  A = ∅
 2  while A 还不是生成树
 3      找一条对 A 安全的边 (u, v)
 4      A = A ∪ {(u, v)}
 5  return A
```

循环不变式：**A 始终是某棵最小生成树的子集**。找"安全边"是全章核心。

### 割（cut）与轻边

- 割 $(S, V-S)$：把顶点集切两半。**割尊重 A**：A 中没有边跨越割。
- **轻边**：跨越割的边中权重最小者。

> **Theorem 21.1**（此 PDF p.765-766）：设 $A$ 是某 MST 的子集，$(S,V-S)$ 是尊重 $A$ 的割，$(u,v)$ 是跨越该割的轻边，则 $(u,v)$ 对 $A$ **安全**（$A \cup \{(u,v)\}$ 仍是某 MST 的子集）。

证明（切割-粘贴法）：设 MST $T \supseteq A$ 不含 $(u,v)$。$T$ 中 $u \to v$ 的唯一路径 $p$ 必跨割（$u,v$ 在割两侧）⇒ $p$ 上有条跨割边 $(x,y)$，且 $(x,y) \notin A$（割尊重 A）。把 $T$ 中的 $(x,y)$ 换成 $(u,v)$ 得 $T'$：仍连通无环（换边保树），$w(T') = w(T) - w(x,y) + w(u,v) \le w(T)$（轻边性质）⇒ $T'$ 也是 MST 且含 $A \cup \{(u,v)\}$。

**Corollary 21.2**（算法实际用的形式）：$A$ 形成的森林中每个连通分量是一棵树；**连接某棵树 $C$ 与森林中另一棵树的最轻边安全**。

### Kruskal：全局排序 + 并查集（§21.2）

```
MST-KRUSKAL(G, w)
 1  A = ∅
 2  for each v ∈ G.V:  MAKE-SET(v)        // 每棵树一个集合
 4  把 G.E 按权重升序排成一个列表
 6  for each edge (u, v) 按序取出
 7      if FIND-SET(u) ≠ FIND-SET(v)      // 不同树 ⇒ 不成环
 8          A = A ∪ {(u, v)}
 9          UNION(u, v)                   // 合并两棵树
10  return A
```

每步选**全局**最轻且连接两片森林的边（Corollary 21.2：它是连接两棵树的最轻边，安全）。**复杂度**：排序 $O(E\lg E)$；$O(E)$ 次 FIND-SET/UNION + $O(V)$ 次 MAKE-SET，用并查集森林（按秩合并+路径压缩）共 $O((V+E)\alpha(V))$。因 $|E| \ge |V|-1$，总 **$O(E\lg V)$**（$\lg E = O(\lg V)$ 因 $|E|<V^2$）。

> 第 19 章的并查集在这里派上用场：Kruskal 的"是否成环"就是 FIND-SET 判同集。

### Prim：单树生长 + 优先队列

```
MST-PRIM(G, w, r)
 1  for each u ∈ G.V:  u.key = ∞;  u.π = NIL
 4  r.key = 0
 5  Q = 所有顶点（以 key 为键的最小优先队列）
 8  while Q ≠ ∅
 9      u = EXTRACT-MIN(Q)                 // 树外离树最近的顶点
10      for each v ∈ G.Adj[u]
11          if v ∈ Q and w(u, v) < v.key    // 到树的距离缩短了
12              v.π = u
13              v.key = w(u, v)
14              DECREASE-KEY(Q, v, w(u, v))
```

$v.key$ = 连接 $v$ 与树的最小边权。每次 EXTRACT-MIN 取树外最近顶点，切 $(V-Q, Q)$ 下 $(u, u.\pi)$ 是轻边（Corollary 21.2 保证安全）。

**复杂度对比**：

| 优先队列实现 | Prim | 说明 |
|---|---|---|
| 数组 | $O(V^2)$ | 适合稠密图 |
| 二叉堆 | $O(E\lg V)$ | 与 Kruskal 渐近相同 |
| **斐波那契堆** | $O(E + V\lg V)$ | DECREASE-KEY $O(1)$ 摊销，$E = \Omega(V\lg V)$ 时线性 |

Prim 与 Dijkstra 形似神合：都是"集合 S + 最小堆选最近 + 松弛邻居"，只是一个维护"到树的最短边"、一个维护"到源的最短距离"。

## 二、单源最短路：松弛框架（§22 引言）

### 模型与约定

权重函数 $w: E \to \mathbb{R}$，路径权 = 边权和，$\delta(u,v)$ = 最短路权。本章用邻接表。核心概念：

- **Lemma 22.1（最优子结构）**：最短路的子路径也是最短路径。
- 最短路**不含负环**（有则 $\delta = -\infty$）、**不含正环**（去掉更短）、**可假设不含零环** ⇒ 最短路是简单路径，至多 $|V|-1$ 条边。
- 前驱 $v.\pi$ 链构成**最短路树**。

### RELAX：唯一的更新机制

```
INITIALIZE-SINGLE-SOURCE(G, s):  所有 v.d = ∞, v.π = NIL;  s.d = 0

RELAX(u, v, w)
 1  if v.d > u.d + w(u, v)
 2      v.d = u.d + w(u, v)
 3      v.π = u
```

本章所有算法 = 初始化 + 反复松弛，区别只在**松多少遍、什么顺序**。五条基石性质：

| 性质 | 内容 |
|---|---|
| 三角不等式 | $\delta(s,v) \le \delta(s,u) + w(u,v)$ |
| 上界性质 | $v.d \ge \delta(s,v)$ 恒成立；一旦取等永不改变 |
| 无路性质 | $s$ 不可达 $v$ ⇒ $v.d = \delta(s,v) = \infty$ |
| 收敛性质 | $s \leadsto u \to v$ 最短且松弛前 $u.d = \delta(s,u)$ ⇒ 松弛后 $v.d = \delta(s,v)$ |
| **路径松弛性质** | 按路径顺序松弛 $p = \langle v_0, \dots, v_k\rangle$ 的边 ⇒ $v_k.d = \delta(s,v_k)$ |

## 三、Bellman-Ford：万能但慢（§22.1）

允许负权边；检测可达负环。

```
BELLMAN-FORD(G, w, s)
 1  INITIALIZE-SINGLE-SOURCE(G, s)
 2  for i = 1 to |V| − 1              // 最多 |V|−1 条边 ⇒ |V|−1 轮
 3      for each edge (u, v) ∈ G.E
 4          RELAX(u, v, w)
 5  for each edge (u, v) ∈ G.E        // 负环检测
 6      if v.d > u.d + w(u, v)
 7          return FALSE
 8  return TRUE
```

**正确性**：无负环时，任意最短路 $\le |V|-1$ 条边，第 $i$ 轮必松弛路径第 $i$ 条边 ⇒ 路径松弛性质 ⇒ $|V|-1$ 轮后全体收敛。有可达负环时，第 $|V|$ 轮检测必有边还能松（否则沿环求和得 $0 \le w(c) < 0$ 矛盾）⇒ 返回 FALSE。

**复杂度**：$O(VE)$（邻接表下每轮扫全图 $O(V+E)$，共 $|V|-1$ 轮；$|E|=\Omega(V)$ 时 $O(VE)$）。优化：记录本轮是否有更新，无更新即停（Ex 22.1-3 提前终止）。

> 记忆口诀：**Bellman-Ford = 全边松弛 ×（顶点数−1）轮**；Dijkstra = 每顶点一次主导的贪心；DAG = 拓扑序松一遍。

## 四、DAG 最短路：一遍拓扑序（§22.2）

DAG 无环 ⇒ 无负环，最短路永远良定义。

```
DAG-SHORTEST-PATHS(G, w, s)
 1  拓扑排序 G 的顶点
 2  INITIALIZE-SINGLE-SOURCE(G, s)
 3  for each u ∈ G.V（按拓扑序）
 4      for each v ∈ G.Adj[u]
 5          RELAX(u, v, w)
```

拓扑序保证处理 $u$ 时所有入边已松过；每条边恰好松一次 ⇒ $O(V+E)$。**PERT 关键路径**就是它的"最长路径版"：边权取反或把 RELAX 的 `>` 换 `<`、初始化换 $-\infty$。

## 五、Dijkstra：非负权的贪心（§22.3）

```
DIJKSTRA(G, w, s)
 1  INITIALIZE-SINGLE-SOURCE(G, s)
 2  S = ∅;  Q = 所有顶点（最小优先队列，键 = d）
 6  while Q ≠ ∅
 7      u = EXTRACT-MIN(Q)             // 取 S 外最近者
 8      S = S ∪ {u}                    // u.d 此时定型
 9      for each v ∈ G.Adj[u]
10          RELAX(u, v, w)
12          DECREASE-KEY(Q, v, v.d)
```

**Theorem 22.6（正确性）**：每次 EXTRACT-MIN 出的 $u$ 满足 $u.d = \delta(s,u)$。归纳：设最短路上 $y$ 是 $S$ 外第一个顶点、$x \in S$ 是其前驱。$x.d = \delta(s,x)$（归纳假设）⇒ 松弛 $(x,y)$ 时 $y.d$ 收到 $\delta(s,y)$（收敛性质）；又 $\delta(s,y) \le \delta(s,u) \le u.d \le y.d$（$u$ 是堆最小 + 非负权保证路上距离单调）⇒ 全部相等。

| 队列实现 | 复杂度 |
|---|---|
| 数组 | $O(V^2)$ |
| 二叉堆 | $O((V+E)\lg V)$，稀疏图优于 $O(V^2)$ 当 $E = o(V^2/\lg V)$ |
| 斐波那契堆 | $O(V\lg V + E)$ |

**Dijkstra 为什么怕负权**：定理证明用了"$\delta(s,y) \le \delta(s,u)$"（最短路先到 $y$ 再到 $u$，非负权保证不绕路更短）。负权边下，晚发现的顶点可能通过负边抄近路，堆最小值不再可信（Ex 22.3-2）。

> 三算法对照：**Bellman-Ford** 是"暴力但万能"（负权+负环检测）；**DAG 版**是"拓扑序一遍过"；**Dijkstra** 是"非负权下的贪心加速"。

## 六、差分约束：最短路的 LP 特例（§22.4）

形如 $x_j - x_i \le b_k$ 的约束组。建**约束图**：$n$ 个未知点 + 超级源 $v_0$；约束 $x_j - x_i \le b_k$ ⇒ 边 $(v_i, v_j)$ 权 $b_k$；$v_0$ 到每个点权 0 边。

**Theorem 22.9**：约束图无负环 $\iff$ 系统有解，且 $x_i = \delta(v_0, v_i)$ 就是一组可行解（三角不等式直接给出约束）；有负环则无解（沿环求和得 $0 \le w(c) < 0$）。Bellman-Ford 解之，$O(nm)$。

## 七、全源最短路（§23）

### 7.1 矩阵乘法式 DP：SLOW / FASTER-APSP

定义 $l^{(r)}_{ij}$ = $i \to j$ 至多 $r$ 条边的最短路：

$$l^{(r)}_{ij} = \min\big\{l^{(r-1)}_{ij},\ \min_k \{l^{(r-1)}_{ik} + w_{kj}\}\}$$

这正是把矩阵乘法的 $(+, \times)$ 换成 $(\min, +)$！SLOW-APSP 连乘 $n-1$ 次 $\Theta(n^4)$；**FASTER-APSP 用重复平方**（"矩阵"乘法满足结合律）$\Theta(n^3 \lg n)$。

### 7.2 Floyd-Warshall：按中间顶点 DP $\Theta(n^3)$

$d^{(k)}_{ij}$ = $i \to j$、中间顶点全在 $\{1,\dots,k\}$ 中的最短路：

$$d^{(k)}_{ij} = \min\big\{d^{(k-1)}_{ij},\ d^{(k-1)}_{ik} + d^{(k-1)}_{kj}\big\}$$

```
FLOYD-WARSHALL(W, n)
 1  D = W
 2  for k = 1 to n                    // 中间顶点编号
 3      for i = 1 to n
 4          for j = 1 to n
 5              dij = min {dij, dik + dkj}    // k 是中转 or 不是
 6  return D
```

三重循环 $\Theta(n^3)$，常数极小（无数据结构），实际非常快。**可原地做**（$d^{(k-1)}$ 与 $d^{(k)}$ 混用不影响，Ex 23.2-4）⇒ $\Theta(n^2)$ 空间。检测负环：跑完后看对角线是否有负值。

**传递闭包**的布尔版：把 min/加 换成 ∨/∧，$t^{(k)}_{ij} = t^{(k-1)}_{ij} \vee (t^{(k-1)}_{ik} \wedge t^{(k-1)}_{kj})$，同样 $\Theta(n^3)$，空间按 bit 存。

### 7.3 Johnson：稀疏图的 $O(V^2\lg V + VE)$

思想：**重加权把负权"洗"成非负，再对每个点跑 Dijkstra**。

**Lemma 23.1（重加权保持最短路）**：任取 $h: V \to \mathbb{R}$，定义

$$\hat w(u,v) = w(u,v) + h(u) - h(v)$$

则任意路径 $p$ 满足 $\hat w(p) = w(p) + h(v_0) - h(v_k)$——路径起点终点固定，偏移量是常数 ⇒ **最短路径集合不变**；环的重量也不变（$h(v_0) = h(v_k)$）。

具体做法：加超级源 $s$（到所有点权 0 边），Bellman-Ford 求 $h(v) = \delta(s, v)$；由三角不等式 $h(v) \le h(u) + w(u,v)$ ⇒ $\hat w(u,v) = w(u,v) + h(u) - h(v) \ge 0$。然后每个点跑 Dijkstra，结果用 $\delta(u,v) = \hat\delta(u,v) - h(u) + h(v)$ 还原。

复杂度：1 次 Bellman-Ford $O(VE)$ + $V$ 次 Dijkstra（斐波那契堆）$O(V(V\lg V + E))$ ⇒ 总 $O(V^2\lg V + VE)$。稀疏图上碾压 Floyd-Warshall。

## 八、例题精讲

### 例题 A（基础）★ Ex 21.1-1：最小权边必在某 MST 中

<details>
<summary>答案</summary>
设 $(u,v)$ 是全图最小权边。任取一棵 MST $T$，若 $(u,v) \in T$ 完事；否则 $T$ 中 $u\to v$ 路径必跨某个割（沿路径上任一条边 $(x,y)$ 定义割：删 $(x,y)$ 后 $T$ 断成两棵树，$u,v$ 分属两侧），且 $w(u,v) \le w(x,y)$（全局最小）。由 Theorem 21.1 的构造，$T' = T - \{(x,y)\} + \{(u,v)\}$ 是等重 MST 且含 $(u,v)$。
</details>

### 例题 B（基础）★ Ex 21.1-5：环上最大边可弃

<details>
<summary>答案</summary>
设 $e$ 是某环 $c$ 上的最大权边。若某 MST $T$ 含 $e$，删 $e$ 后 $T$ 断成两棵树 $T_1, T_2$；环上 $e$ 两端点分属两侧，环上其余某边 $(x,y)$ 也跨这两侧，$w(e) \ge w(x,y)$（环上最大）。把 $e$ 换成 $(x,y)$ 得新 MST $T'$ 不含 $e$ 且 $w(T') \le w(T)$。⇒ 存在不含 $e$ 的 MST。（这正是 Kruskal 敢跳过成大环边的理论依据。）
</details>

### 例题 C（进阶）★ Ex 22.3-2：Dijkstra 的负权反例

<details>
<summary>答案</summary>
四顶点图：$s \to a$ 权 1，$a \to b$ 权 1，$s \to b$ 权 2，$b \to a$ 权 $-1.5$。

- 真实最短：$\delta(s,a) = 0.5$（走 $s \to b \to a = 2 - 1.5$）。
- Dijkstra 执行：初始 $s.d=0$，其余 ∞。出 $s$：松弛得 $a.d=1,\ b.d=2$。堆里 $a$（1）小于 $b$（2）⇒ 出 $a$，松弛 $a \to b$ 不改进。出 $b$：松弛 $b \to a$ 想把 $a.d$ 刷成 0.5，**但 $a$ 已出队定型**，算法不再更新。最终输出 $a.d = 1 \ne \delta(s,a) = 0.5$。

错因：$a$ 出队时它的最短距离还没被后面的负边 $(b,a)$ 改善。定理证明里"$\delta(s,y) \le \delta(s,u)$"依赖非负权保证"先到 $y$ 再到 $u$ 不绕路更短"，负边下这条链断了。
</details>

### 例题 D（进阶）★ Ex 22.4-3：约束图里 $\delta(v_0, v_i)$ 能是正的吗？

<details>
<summary>答案</summary>
不能。$v_0$ 到每个 $v_i$ 有直接边权 0 ⇒ $\delta(v_0, v_i) \le 0$ 恒成立；若某路径给出正值，那条 0 权直连边只会更短，矛盾。推论：可行解 $x_i = \delta(v_0, v_i)$ 全部 $\le 0$；若题目另有 $x_i \ge 0$ 的要求，需往约束系统里补 $-x_i \le 0$ 型约束。
</details>

### 例题 E（进阶）★ Ex 23.1-4：min-plus"矩阵乘法"满足结合律

<details>
<summary>答案</summary>
记 $C = A \otimes B$，$c_{ij} = \min_k(a_{ik} + b_{kj})$。证 $(A \otimes B) \otimes D = A \otimes (B \otimes D)$：两边都等于

$$\min_{k_1, k_2} \big(a_{ik_1} + b_{k_1k_2} + d_{k_2j}\big)$$

左边先对内层 $k_2$ 取 min 得 $(B \otimes D)_{k_1j}$，再对 $k_1$；右边先对 $k_1$。min 与 + 都满足结合/交换律，且 min 对 + 满足分配律（$\min\{a+c,\, b+c\} = \min\{a,b\} + c$）⇒ 相等。这正是 FASTER-APSP 能重复平方的许可证。
</details>

### 例题 F（进阶）★ 自编模拟：Kruskal 与 Prim 会选同一棵 MST 吗？

<details>
<summary>答案</summary>
不一定，但总权重一定相同。Kruskal 的森林是多棵树（割在"树 vs 树"之间），Prim 的是一棵单树（割在"树内 vs 树外"）；二者都只用 Corollary 21.2 的轻边规则，但面对的割不同，遇平局时选择可以不同。

构造（4 个顶点排成菱形）：顶点 1-2-3-4-1 成环，四条边权都是 1，对角线 1-3 权 0.5。
- Kruskal：先拿 1-3（0.5）；再按顺序拿 1-2、2-3（此时 {1,2,3} 连通，跳过 3-4？不——3-4 连接两棵树，拿）；拿 3-4 后 {1,2,3,4} 全通，跳过 4-1。MST = {1-3, 1-2, 2-3, 3-4}。
- Prim 从 1 出发：先拿 1-3（0.5）；1 的其他邻边 1-2、4-1 权 1，3 的邻边 2-3、3-4 权 1，平局时按实现选——若选 4-1：树 {1,3,4}；下一步 3-4 会成环跳过，拿 2-3 ⇒ MST = {1-3, 4-1, 2-3}（+ 还需连 2：2-3 已拿，完成）。

两者边集不同、总重都是 3.5。**结论：MST 不唯一时算法结果依赖实现细节；MST 唯一时所有正确算法必得同一棵树**（Ex 21.1-6：若每个割都有唯一轻边，则 MST 唯一）。
</details>

## 九、习题与答案

**习题 1** ★（Ex 22.1-3，此 PDF p.796）提前终止：如何改 Bellman-Ford 使其在无负环时用 $m+1$ 轮停止（$m$ = 最短路边数的最大值）？

<details>
<summary>答案</summary>
每轮维护一个 flag：本轮是否有任何 $d$ 值被更新。无更新 ⇒ 已收敛（所有最短路的边都已被按序松弛过，路径松弛性质），立即 break。设 $m$ 为所有最短路边数的最大值，则第 $m+1$ 轮必无更新（第 $m$ 轮已把最后一条边松完），所以至多 $m+1$ 轮。
</details>

**习题 2** ★★（Ex 22.2-2，此 PDF p.803）DAG-SHORTEST-PATHS 若只处理拓扑序前 $|V|-1$ 个顶点（跳过最后一个），为什么仍正确？

<details>
<summary>答案</summary>
拓扑序最后一个顶点 $z$ 没有出边（否则它的出边邻居应排在它后面，矛盾）。因此跳过 $z$ 只是不松弛"从 $z$ 出发的边"——这样的边不存在。$z$ 的 $d$ 值在自己被处理前的入边松弛中已定型：任意最短路到 $z$ 的路径上所有顶点都不晚于 $z$ 的拓扑位，路径最后一条边 $(u,z)$ 在处理 $u$（前 $|V|-1$ 个之一）时已松弛 ⇒ 收敛性质 ⇒ $z.d = \delta(s,z)$。
</details>

**习题 3** ★★（Ex 22.3-7，此 PDF p.811）边有"可靠性" $r(u,v) \in [0,1]$（独立不失效概率），找最可靠路径。

<details>
<summary>答案</summary>
路径可靠度 = 路径上所有边 $r$ 的**乘积**（边独立）。取对数变加法：$w(u,v) = -\ln r(u,v) \ge 0$（$r \le 1$ ⇒ $-\ln r \ge 0$），最大化乘积 = 最小化和 ⇒ Dijkstra。$r=0$ 的边置 $w=\infty$（不可用）。找到最短路后可靠度 = $e^{-w(p)}$。复杂度 $O((V+E)\lg V)$。
</details>

**习题 4** ★★（Ex 22.3-9，此 PDF p.811）边权为 $\{0,1,\dots,W\}$ 的小整数，修改 Dijkstra 到 $O(WV + E)$。

<details>
<summary>答案</summary>
观察：$V-S$ 中所有顶点的 $d$ 值都在一个宽度 $\le W$ 的窗口内（堆顶 $u$ 出队后新发现的 $v$ 满足 $v.d = u.d + w(u,v) \le u.d + W$）。用 **Dial 算法**：$W+1$ 个桶的循环数组，第 $i$ 桶装当前 $d = \text{base} + i$ 的顶点；EXTRACT-MIN 从 base 桶往后找第一个非空桶（均摊每顶点跨桶总次数 $O(WV)$）；DECREASE-KEY 只会往更小的桶放（回退不超过 $W$）。总 $O(WV + E)$。
</details>

**习题 5** ★★（Ex 23.2-4，此 PDF p.857）为什么 Floyd-Warshall 可以原地更新（省一维）？

<details>
<summary>答案</summary>
第 $k$ 轮用到的 $d^{(k-1)}_{ij}$、$d^{(k-1)}_{ik}$、$d^{(k-1)}_{kj}$：原地更新后，$d_{ik}$ 与 $d_{kj}$ 在本轮中**先于** $d_{ij}$ 被更新（即 $i=k$ 或 $j=k$ 的项先算）——而无负环时 $d_{kk} \ge 0$，故 $d^{(k)}_{ik} = \min\{d^{(k-1)}_{ik},\ d^{(k-1)}_{ik} + d^{(k-1)}_{kk}\} = d^{(k-1)}_{ik}$，$d^{(k)}_{kj}$ 同理。所以三重循环里 $d_{ij} = \min\{d_{ij},\ d_{ik} + d_{kj}\}$ 用当前值计算结果正确，只需 $\Theta(n^2)$ 空间。（有负环时 $d_{kk}$ 可能变负，原地版会算出 $-\infty$ 传播——恰好可用于负环检测。）
</details>

**习题 6** ★★★（Ex 23.3-4，此 PDF p.864）Professor Greenstreet 提议重加权直接 $\hat w(u,v) = w(u,v) - w^*$（$w^*$ = 全局最小边权）。错在哪？

<details>
<summary>答案</summary>
错在**混淆了"边权平移"与"势函数重加权"**。Lemma 23.1 的 $\hat w(u,v) = w(u,v) + h(u) - h(v)$ 沿路径望远镜相消：$\hat w(p) = w(p) + h(v_0) - h(v_k)$，偏移量与路径无关。而常数平移是**每条边**都减 $w^*$，路径上减了 $k$ 次（$k$ = 边数）：$\hat w(p) = w(p) - k\cdot w^*$，偏移量随路径长度累积 ⇒ **路径之间的比较被改变**，最短路径集合可能面目全非。

反例：$s \to a$ 权 $-1$，$a \to b$ 权 $-1$，$s \to b$ 权 $-1.5$。原最短路是 $s \to a \to b$（$-2$）。$w^* = -1.5$，平移后 $\hat w(s,a) = 0.5$，$\hat w(a,b) = 0.5$，$\hat w(s,b) = 0$：两段路新权 1.0，直连 0 ⇒ 最短路径变成直连，**错误**。修正必须用势函数（顶点势），如 Johnson 的 $h(v) = \delta(s,v)$。
</details>

**习题 7** ★★★（自编模拟）Floyd-Warshall 如何检测负环？为什么 Dijkstra×V 不能？

<details>
<summary>答案</summary>
FW 结束后若存在 $i$ 使 $d_{ii} < 0$，说明存在可达负权环（$d^{(n)}_{ii} = \delta(i,i)$，无负环时为 0；有负环时 DP 会把它压成负值）。检测法：跑完后查对角线。Dijkstra×V 不能检测：Dijkstra 的正确性证明本身要求非负权，负权下输出的 $d$ 值无意义，无法从结果推断负环存在——检测负环必须用 Bellman-Ford（专门的检测轮）或 FW（对角线）。
</details>

**本篇小结**：MST 的引擎是"割 + 轻边"定理，Kruskal/Prim 只是选轻边的两种数据组织方式；最短路全章建立在"松弛 + 五性质"的骨架上，Bellman-Ford/Dijkstra/DAG 版的差别是松弛的顺序与轮数；全源问题里 Floyd-Warshall 用"中间顶点集合"DP 以紧凑三重循环取胜，Johnson 用势函数重加权把负权图洗成非负再批量 Dijkstra。图算法部分的最后一站：最大流与二分图匹配。
