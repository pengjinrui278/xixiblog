## 一、二叉搜索树：一条性质通吃（§12.1）

### 【定义】二叉搜索树性质

> **原文摘录**（§12.1，此 PDF p.420）
> "Let $x$ be a node in a binary search tree. If $y$ is a node in the left subtree of $x$, then $y.key \le x.key$. If $y$ is a node in the right subtree of $x$, then $y.key \ge x.key$."

每个节点的左子树全部 $\le$ 它、右子树全部 $\ge$ 它。这把"有序"从**线性排列**改写成了**层次约束**。

### 【定理 12.1】中序遍历 $\Theta(n)$

```
INORDER-TREE-WALK(x)
 1  if x ≠ NIL
 2      INORDER-TREE-WALK(x.left)
 3      print x.key
 4      INORDER-TREE-WALK(x.right)
```

**正确性**：由 BST 性质直接归纳。**线性性**：$T(n) \le T(k) + T(n-k-1) + d$，代入法证 $T(n)\le (c+d)n + c$（此 PDF p.422-423，Substitution 的又一次亮相）。

### BST 性质 vs 堆性质（Ex 12.1-2）

| | BST | 最小堆 |
|---|---|---|
| 约束方向 | 左右子树**分裂**（左全小、右全大） | 父 $\le$ 两个孩子（只局部有序） |
| 中序遍历 | **有序** | 无序 |

堆性质**不能** $O(n)$ 输出有序序列——堆的全局无序，这正是堆排序必须"不断 EXTRACT-MAX 重堆化"的原因。

### 【图示】同键不同形

键集 $\{2,5,5,6,7,8\}$ 的两副面孔（此 PDF p.420-421）：

```
   高 2（好）            高 4（差）
       6                     6
     /   \                 /   \
    5     7               2     7
   / \     \             / \     \
  2   5     8           5   5     8
```

查询时间只取决于**高度** $h$。构造 BST 的插入顺序决定了形状：有序插入退化成链表，最坏 $\Theta(n)$。

## 二、查询四件套与 TREE-SUCCESSOR（§12.2）

```
TREE-SEARCH(x, k)                    TREE-MINIMUM(x)
 1  if x == NIL or k == x.key           1  while x.left ≠ NIL
 2      return x                        2      x = x.left
 3  if k < x.key                        3  return x
 4      return TREE-SEARCH(x.left, k)   TREE-MAXIMUM(x) 对称，一路向右
 5  else return TREE-SEARCH(x.right, k)
```

全部走一条从根向下的简单路径，$O(h)$。

### TREE-SUCCESSOR 的两种情形

```
TREE-SUCCESSOR(x)
 1  if x.right ≠ NIL
 2      return TREE-MINIMUM(x.right)      // 情形一：右子树非空
 3  else
 4      y = x.p                          // 情形二：一路向上
 5      while y ≠ NIL and x == y.right
 6          x = y
 7          y = y.p
 8      return y
```

**图示**（此 PDF p.425）：

```
情形一：15 的后继是 17        情形二：13 的后继是 15
        15                            15
       /  \                          /  \
      6    17   ← 右子树最左         6    20
     / \                            /
    7   13  ← 一路向右到黑后,       7
        向上到"第一个左拐的祖先"     \
                                   13
```

**一句话记忆**：有右子树——右子树最左；没右子树——第一个"从左边上来"的祖先。$O(h)$。

### 【定理 12.2】查询全家 $O(h)$

SEARCH、MINIMUM、MAXIMUM、SUCCESSOR、PREDECESSOR 全部 $O(h)$。

### 【例题 12.2-1】哪条搜索路径不可能？

在 $\{1,\dots,1000\}$ 的 BST 中搜 363：

| 序列 | 合法？ | 理由 |
|---|---|---|
| (a) 2, 252, 401, 398, 330, 344, 397, 363 | ✅ | 每步方向与比较一致 |
| (b) 924, 220, 911, 244, 898, 258, 362, 363 | ✅ | |
| (c) 925, 202, 911, 240, **912**, 245, 363 | ❌ | 911 后应往左找 $<$911 的，912 却在右 |
| (d) 2, 399, 387, 219, 266, 382, 381, 278, 363 | ✅ | |
| (e) 935, 278, 347, 621, 299, 392, 358, 363 | ✅ | |

**判别法**：搜索路径必须是"一路向下 + 大小交替正确"的简单路径。

## 三、插入与删除：四种情形（§12.3）

### TREE-INSERT

与 SEARCH 同构：一路向下找 NIL，用**尾指针 $y$** 记下最后一个非 NIL 节点（它就是新节点的父亲）。$O(h)$。

### TREE-DELETE 的四种情形

```
TRANSPLANT(T, u, v)          // 用子树 v 顶替子树 u（v 可为 NIL）
 1  if u.p == NIL
 2      T.root = v
 3  elseif u == u.p.left
 4      u.p.left = v
 5  else u.p.right = v
 6  if v ≠ NIL
 7      v.p = u.p
```

**核心武器**：TRANSPLANT 只动"u 与父节点的关系"，不动 v 的孩子——调用方负责。

四种情形（此 PDF p.432，Figure 12.4）：

```
(a) z 无左孩            (b) z 无右孩           (c) z 两孩子且后继 y = z.right
    q                     q                       q
    |                     |                       |
    z                     z                       z
     \                   /                       /  \
      r     ⇒    l      l       ⇒               l    y
                                                       \
                                                        x

(d) z 两孩子且后继 y 在右子树深处
    q                     q
    |                     |
    z                     y
   / \                   / \
  l   r        ⇒       l   r
     / \                   / \
    ·   y                 ·   x
         \
          x
```

**TREE-DELETE 结构**：

```
TREE-DELETE(T, z)
 1  if z.left == NIL
 2      TRANSPLANT(T, z, z.right)      // 无左孩（含无孩子）：右孩顶上
 3  elseif z.right == NIL
 4      TRANSPLANT(T, z, z.left)       // 无右孩：左孩顶上
 5  else y = TREE-MINIMUM(z.right)     // 两孩子：找后继 y（必无左孩）
 6      if y ≠ z.right
 7          TRANSPLANT(T, y, y.right)  // 先把 y 摘出去（其右孩补位）
 8          y.right = z.right          // z 的右子树挂给 y
 9          y.right.p = y
10      else x.p = y                   // (y == z.right 时处理哨兵)
11      TRANSPLANT(T, z, y)            // y 顶替 z
12      y.left = z.left                // z 的左子树挂给 y
13      y.left.p = y
```

**为什么用后继而不是前驱**？任意；用后继是因为"后继没有左孩子"，摘出去只需处理它的右孩。全部 $O(h)$。

### 【定理 12.3】INSERT/DELETE 均 $O(h)$。

### 【例题 12.3-3】BST 排序

反复 TREE-INSERT + 中序遍历 = 树排序。最好（平衡）$\Theta(n\lg n)$，最坏（退化）$\Theta(n^2)$。**顺带证明**（Ex 12.1-5）：比较模型下建 BST 最坏 $\Omega(n\lg n)$——否则就得到了更快的排序。

## 四、红黑树：一比特换平衡（§13.1）

### 【定义】红黑五性质

> **原文摘录**（§13.1，此 PDF p.443）
> 1. Every node is either red or black.
> 2. The root is black.
> 3. Every leaf (NIL) is black.
> 4. If a node is red, then both its children are black.
> 5. For each node, all simple paths from the node to descendant leaves contain the same number of black nodes.

每个节点多存 1 比特 color。性质 4 禁止"红红相连"，性质 5 统一每条路径的黑数——两条性质合谋，把最长路径压到最短的至多两倍。

**哨兵 $T.nil$**：所有 NIL 合并成一个黑色哨兵对象，父指针可达、免边界判断（§10.2 哨兵思想的正规军）。RB-TRANSPLANT 甚至可以**无条件写 $v.p$**（哪怕 $v$ 是哨兵）——删除修复的关键伏笔。

### 【定义】黑高度 $bh(x)$

从 $x$（不含）到后代叶子的简单路径上的黑节点数。性质 5 保证它是良定义的。

### 【引理 13.1】红黑树高度 $\le 2\lg(n+1)$

**证明**（此 PDF p.444-446）：
1. 以 $x$ 为根的子树至少含 $2^{bh(x)}-1$ 个内部节点（对高度归纳：黑孩子贡献 $bh(x)-1$、红孩子 $bh(x)$，两个孩子都 $\ge 2^{bh(x)-1}-1$，加自己）。
2. 性质 4：根到叶路径（除根）**至少一半是黑** ⇒ $bh(\text{root}) \ge h/2$。
3. $n \ge 2^{h/2}-1$ ⇒ $h \le 2\lg(n+1)$。

**读法**：性质 5 管"黑高度齐"，性质 4 管"红不连续所以红最多占一半"。两步接力，$O(\lg n)$ 到手——所有动态集操作从此免费提速到 $O(\lg n)$。

### 【例题 13.1-4】黑结点吸收红孩子

若黑结点"吸收"所有红孩子（红孩子消失、其子女过继给黑父），得到的是一棵 **2-3-4 树**：每个黑结点度数为 2、3 或 4（原黑 + 最多两个红孩子各带两个黑孩子），且所有叶子同深。红黑树正是 2-3-4 树的二叉树化身。

### 【例题 13.1-7】红黑比最大/最小

最大红黑比：根黑、其余全红（根带两红孩、每红孩带两黑哨兵）⇒ 红:黑 = 2:1；最小：全黑 ⇒ 1:0（无红）。

## 五、旋转：局部手术保 BST 性质（§13.2）

### 【定义】旋转

**左旋 LEFT-ROTATE(T, x)**：把 $x$ 与右孩子 $y$ 之间的边"拧"向左——$y$ 上位成子树根，$x$ 降为 $y$ 的左孩子，$y$ 的原左子树 $\beta$ **过继给 $x$ 当右子树**：

```
旋转前                  旋转后
      x                    y
     / \                  / \
    α   y       ⇒        x   γ
       / \              / \
      β   γ            α   β
```

```
LEFT-ROTATE(T, x)
 1  y = x.right
 2  x.right = y.left            // β 过继给 x
 3  if y.left ≠ T.nil
 4      y.left.p = x
 5  y.p = x.p                   // y 顶替 x 的亲子关系
 6  if x.p == T.nil
 7      T.root = y
 8  elseif x == x.p.left
 9      x.p.left = y
10  else x.p.right = y
11  y.left = x
12  x.p = y
```

**要点**：
- $O(1)$ 时间、只改指针；
- **保持中序序列不变**：$\alpha < x < \beta < y < \gamma$ 的次序在旋转前后一致（此 PDF p.450-451，Figure 13.3）——这是 BST 性质不坏的数学根据；
- 每棵 $n$ 结点树恰有 $n-1$ 种可执行的旋转（Ex 13.2-2：每条边都可拧一次）；
- 深度变化（Ex 13.2-3）：$a$（$\alpha$ 中）深 1，$b$（$\beta$ 中）浅 1，$c$（$\gamma$ 中）不变。旋转就是**深度搬运工**。

## 六、RB-INSERT：先插入再修复（§13.3）

### 流程

1. 普通 BST 插入（TREE-INSERT 换哨兵版）；
2. 新节点 $z$ 涂**红**（Ex 13.3-1：若涂黑，沿 $z$ 的路径黑数 +1，性质 5 立刻崩，修复代价大得多）；
3. RB-INSERT-FIXUP 收拾残局。

涂红只会坏两条性质：性质 2（$z$ 是根且红）、性质 4（$z.p$ 也红）。

### 【不变式】RB-INSERT-FIXUP 的循环不变式

每次迭代开始时：
- (a) $z$ 是红的；
- (b) 若 $z.p$ 是根，则 $z.p$ 是黑的；
- (c) 至多违反一条性质，且只可能是 2 或 4；若违 4，则恰是 $z$ 与 $z.p$ 双红。

### 三个情形（$z.p$ 是左孩子；右孩子完全对称）

```
记号：z.p 红（违反4），y = z.p.p.right 是叔叔，z.p.p 必黑
```

**Case 1：叔叔 $y$ 红**（Figure 13.5）

```
    (黑) z.p.p                (红) z.p.p
    /    \                    /    \
 (红)z.p  (红)y      ⇒     (黑)z.p  (黑)y
   /                        /
(红)z                    (红)z'
```

动作：$z.p$、$y$ 涂黑，$z.p.p$ 涂红，$z$ 上移两层。**"黑色下沉一层"**——祖父的黑转让给父和叔，祖父变红。$z$ 成了新的红节点，可能继续违反性质 4（若新父亲也红），循环继续。

**Case 2：叔叔黑，$z$ 是右孩子**（Figure 13.6 左）

```
    (黑) z.p.p              (黑) z.p.p
    /    \                  /    \
 (红)z.p  (黑)y   ⇒      (红)z    (黑)y
     \                    /
    (红)z              (红)z.p
```

动作：左旋 $z.p$。把 Case 2 **拧成 Case 3** 的形状（内侧孙变外侧孙），颜色不动、黑高度不变。

**Case 3：叔叔黑，$z$ 是左孩子**（Figure 13.6 右）

```
    (黑) z.p.p              (黑) z.p
    /    \                  /    \
 (红)z.p  (黑)y   ⇒      (红)z    (红)z.p.p
   /                              \
(红)z                              (黑)y
```

动作：$z.p$ 涂黑、$z.p.p$ 涂红、右旋 $z.p.p$。双红消失，$z.p$ 上位且黑——**循环终止**。

最后第 30 行把根涂黑（处理"$z$ 一路红到根"的 Case 1 尾巴）。

### 【复杂度】

循环只在 Case 1 时继续且 $z$ 每次上移两层 ⇒ 迭代 $O(\lg n)$ 次；旋转只在 Case 2/3 出现 ⇒ **至多 2 次旋转**。RB-INSERT 共 $O(\lg n)$。

### 【例题 13.3-2】逐步插入

依次插入 41, 38, 31, 12, 19, 8：

```
插41(黑)   插38(红)   插31(红)→叔叔38红:C1   插12(红)→叔叔31红:C1
   41        41(B)        31(B)              38(B)          [19插入前]
             /            /  \               /  \
          38(R)        12(R) 41(R)        12(R) 41(R)
            \           /                   /
           31(R)      38(R)              31(R)
                                             \
                                            19(R)
```

（插 31 后：38 与 31 双红、叔叔是哨兵黑、31 是 38 的右孩子 → Case 2 左旋 → Case 3。如上图中部形态。）插 12、19、8 同理各触发一次 Case 1 或 2+3 组合，最终：

```
            38(B)
           /     \
        12(B)    41(B)
        /   \        \
      8(R) 31(R)      (…)
             \
            19(R)
```

**练习建议**：拿纸笔画三遍（叔红/内孙/外孙），红黑树就通了。

## 七、RB-DELETE：双黑结点的漂流（§13.4）

### 删除的结构

与 TREE-DELETE 同构，但多跟踪两个变量：
- $y$：真正被摘下或移动的结点（$z$ 至多一个孩子时 $y=z$；否则 $y=z$ 的后继）；
- $x$：顶替 $y$ 原位的结点（$y$ 无孩时为哨兵 $T.nil$）；
- $y\text{-original-color}$：$y$ 被摘前的颜色。

**只有 $y$ 原本是黑色才可能出事**——要调 RB-DELETE-FIXUP(T, x)。

### 【核心概念】双黑（doubly black）

摘掉一个黑结点 $y$，所有经过 $y$ 的路径黑数 -1，性质 5 破。补救：把 $y$ 的黑色**过继给顶位的 $x$**——$x$ 变成**双黑**（算两重黑）或**红黑**（红 + 一重额外黑，算一重黑）。双黑不是颜色属性，而是"指针 $x$ 多背了一重黑"的记账手法。修复的目标：把这笔账**向上移交或销账**，直到：
1. $x$ 是红黑 → 涂单黑（第 44 行）；
2. $x$ 是根 → 额外黑凭空蒸发；
3. 旋转+染色后销账。

### 四个情形（$x$ 是左孩子；右孩子对称）

```
记号：x 双黑，w = x.p.right 是兄弟。w 必非哨inel——否则 x.p 到 w 路径黑数不敌 x 侧。
```

**Case 1：兄弟 $w$ 红**（Figure 13.7(a)）

```
    (c)B? 注：D=x.p              (红)D
    /    \                       /    \
 (双黑)x  (红)w      ⇒        (黑)B   (黑)w′
         / \                          / \
      (黑)C (黑)E                  (黑)C (黑)E
```

动作：$w$ 涂黑、$x.p$ 涂红、左旋 $x.p$、更新 $w$。**把红兄弟转成黑兄弟**，Case 1 降解为 2/3/4 之一。黑高度全程守恒（$x$ 侧多背的一重黑没动）。

**Case 2：兄弟 $w$ 黑，$w$ 的两个孩子都黑**（Figure 13.7(b)）

```
    (c) D                       (c) D
    /    \                      /    \
 (双黑)x  (黑)w       ⇒       (红黑)x  (红)w
         / \                          / \
       (黑)C (黑)E                (黑)C (黑)E
```

动作：$w$ 涂红，**$x$ 上移一层到 $x.p$**。双黑向上移交：$x$ 侧销掉一重（$w$ 也少一重，扯平），$x.p$ 多背一重。这是**唯一会让循环继续**的情形。若 $x$ 的新颜色属性是红（经由 Case 1 进来），循环即停，第 44 行涂黑。

**Case 3：兄弟 $w$ 黑，$w$ 的近侧孩子红、远侧黑**（Figure 13.7(c)）

```
    (c) D                       (c) D
    /    \                      /    \
 (双黑)x  (黑)w       ⇒       (双黑)x  (红)w
         / \                            \
      (红)C (黑)E                     (黑)C′
```

动作：$w$ 与 $w.left$ 换色、右旋 $w$。把 Case 3 **拧成 Case 4**（红孩子挪到远侧），黑高度不变。

**Case 4：兄弟 $w$ 黑，远侧孩子红**（Figure 13.7(d)）

```
    (c) D                       (c) B
    /    \                      /    \
 (双黑)x  (黑)w       ⇒       (黑)x  (红)D
         / \                            \
      (黑)C (红)E                     (黑)C (黑)E
```

动作：$w$ 取 $x.p$ 的颜色、$x.p$ 涂黑、$w.right$ 涂黑、左旋 $x.p$、$x \leftarrow$ 根。**销账完成**：$x$ 侧补回一重黑（$w$ 的远侧红孩变黑顶上来），$x.p$ 那重原色被 $w$ 继承——循环终止。

### 黑高度守恒验证法（Ex 13.4-6）

定义 $\text{count}(\text{RED})=0$、$\text{count}(\text{BLACK})=1$，逐个数每个 $\alpha,\beta,\dots,\zeta$ 子树根路径上的黑数（含 $x$ 的额外黑），变换前后相等。以 Case 1 为例：$\alpha$、$\beta$ 路径变换前后都是 3（$D$ 黑 + $B$ 黑 + $x$ 额外黑 → $D$ 红 0 + $B$ 黑 1 + $x$ 额外 1 + …）。**每个情形都应这样数一遍**，这是理解而非背诵删除修复的唯一正道。

### 【复杂度】

Case 1/3/4 各 $O(1)$ 染色 + 至多 3 次旋转后终止；Case 2 不旋转但 $x$ 上移，至多 $O(\lg n)$ 次。**RB-DELETE 共 $O(\lg n)$、至多 3 次旋转**（此 PDF p.470-471）。

### 【例题 13.4-1】$y$ 红则无事发生

$y$ 红 ⇒（Ex 13.4-1）黑高度全不变（$y$ 不贡献黑）；红结点的父子必黑，顶位的黑孩子 $x$ 上位不会制造双红；红结点不可能是根。三条齐了，直接跳过修复。

### 【例题 13.4-7】Case 1 入口处 $x.p$ 必黑

 Professors Skelton 和 Baron 担心 Case 1 里 $x.p$ 可能红。**不会**：进入循环时不变式保证"若违性质 4 只可能是 $x$ 与 $x.p$ 双红"，而 $x$ 双黑意味着其下路径黑数偏多，双红会让 $w$ 侧的黑数无论如何对不齐（性质 5 已破的更多）。严格讲：若 $x.p$ 红，则 $x.p$ 的黑孩子 $w$ 的红兄弟路径黑数与 $x$ 侧矛盾于不变式 (c)——至多违反一条性质。所以 $x.p$ 黑，Case 1 安全。

## 八、红黑树全景总结

| 操作 | 时间 | 旋转次数 |
|---|---|---|
| SEARCH / MIN / MAX / SUCCESSOR | $O(\lg n)$ | 0 |
| INSERT | $O(\lg n)$ | $\le 2$ |
| DELETE | $O(\lg n)$ | $\le 3$ |

**设计哲学回望**：
- 旋转 = **保持中序的深度搬运**（局部、$O(1)$、不改 BST 性质）；
- 插入修复 = 双红逐层**上浮**（叔红时染色下沉，叔黑时旋转定型）；
- 删除修复 = 双黑逐层**上移**（兄弟红先转黑，兄弟两黑就上交，一红就拧成远侧红销账）；
- 哨兵 = 把 NIL 变成"永远在线的黑色对象"，消掉一切边界特判。

### 其他平衡树速览（此 PDF p.476-477）

- **AVL**（Prob 13-3）：高度平衡（左右高差 $\le 1$），高度更紧（$1.44\lg n$），插入删除旋转 $O(\lg n)$ 次，查询更快但写更频繁的场景吃亏；
- **2-3 树 / B 树**（第 18 章）：多路平衡，磁盘友好；
- **Treap**：BST × 堆，随机优先级，期望 $O(\lg n)$；
- **Splay**：自调整，摊还 $O(\lg n)$，无需显式平衡条件；
- **Skip list**：链表加多层索引，期望 $O(\lg n)$。

## 九、例题精选（难度递进）

### 例题 A（基础）★ Ex 12.2-5

两孩子的结点，其后继无左孩、前驱无右孩。

**解**：后继 = 右子树最小，若有左孩则左孩更小，矛盾；前驱 = 左子树最大，若有右孩则右孩更大，矛盾。

### 例题 B（基础）★ Ex 13.1-5

红黑树中从结点 $x$ 到叶的最长路径 $\le 2\times$ 最短路径。

**解**：最短路径全黑，长 $bh(x)$；最长路径红黑交替，红不超过黑 ⇒ 长 $\le 2bh(x)$。

### 例题 C（进阶）★ Ex 13.2-4

任意 $n$ 结点 BST 可用 $O(n)$ 次旋转变成任意其他 $n$ 结点 BST。

**解**：提示——至多 $n-1$ 次右旋可把任意树拉成右链（每次对左孩子右旋，链长 +1，$n-1$ 次到顶）；两个目标各自 $O(n)$ 步到链，合起来 $O(n)$。

### 例题 D（综合）★ Ex 13.4-2

RB-DELETE-FIXUP 结束后根必黑。

**解**：循环退出条件 $x$ 是根或 $x$ 黑。若 $x$ 是根且双黑，额外黑蒸发，但 $x$ 的颜色属性可能是红（红黑情形）——第 44 行无条件涂黑。若 $x$ 黑循环本就不进。故根必黑。

### 例题 E（综合）★ 改编 Ex 13.4-9

RB-ENUMERATE(T, r, a, b)：输出子树中 $[a,b]$ 内全部键，$\Theta(m+\lg n)$（$m$ 为输出个数，$a,b$ 都是键）。

**解**：先 $O(\lg n)$ 定位 $a,b$ 的分裂点；从 $a$ 沿"最左公共路径"向上记录右岔口的左子树（这些全部 $\le b$）；向下用 TREE-MINIMUM/TREE-SUCCESSOR 逐个吐 $m$ 个，每个均摊 $O(1)$（Ex 12.2-7：$n-1$ 次 SUCCESSOR 共 $\Theta(n)$）。合计 $\Theta(m+\lg n)$。

## 十、习题与参考答案

> 混合书中原题（标注编号）与自编模拟题（标注"模拟"）。

### 第 12 章

**12.2-7**（★）TREE-MINIMUM + $n-1$ 次 TREE-SUCCESSOR 的中序遍历共 $\Theta(n)$。
<details>
<summary>答案</summary>
$n-1$ 次后继调用中，第 $i$ 次走的路径长度（向上段 + 向下段）之和恰是中序遍历的边遍历总量——每个结点最多被向上经过一次（作为某路径的尾部）和向下经过一次（进入其右子树时）。总步数 $\le 2n$，故 $\Theta(n)$。形式化用摊还：给每个结点存两个"令牌"（进/出）。
</details>

**12.3-2** 搜索访问的结点数 = 1 + 当初插入时访问的结点数。
<details>
<summary>答案</summary>
插入走的路径 = 从根到新结点父的路径；搜索同一键走同一条比较路径直到命中该结点——每步比较结果由键值唯一决定，与先后无关。故搜索路径 = 插入路径 + 目标结点本身。
</details>

**模拟 12-M1**（★）把有序数组 $\langle1,\dots,15\rangle$ 建成高度最小的 BST，求其中序遍历与先序遍历。
<details>
<summary>答案</summary>
递归取中点数：根 8，左 {1-7}（根 4），右 {9-15}（根 12）。中序 = 1..15；先序 = 8, 4, 2, 1, 3, 6, 5, 7, 12, 10, 9, 11, 14, 13, 15。这正是"平衡 BST 从有序数组构建"的标准做法，$O(n)$。
</details>

**模拟 12-M2**（★★）证明：BST 删除两孩子结点时，若改用"前驱顶替"而非后继，代码只需把 left/right 对调。
<details>
<summary>答案</summary>
前驱 = 左子树最大，必无右孩（对称于 Ex 12.2-5）。TREE-DELETE 中：$y = $ TREE-MAXIMUM(z.left)；若 $y \ne z.left$ 先 TRANSPLANT(T, y, y.left) 再把 z.left 挂给 y；TRANSPLANT(T, z, y) 后 y.right = z.right。所有方向取反即得，其余不动。
</details>

### 第 13 章

**13.3-1**（★）新结点为何涂红不涂黑？
<details>
<summary>答案</summary>
涂红只可能违反性质 2/4（局部、可修复）；涂黑则使所有过 $z$ 的路径黑数 +1，性质 5 系统性破坏，修复要重新平衡多条路径的黑高度，代价远大。红黑树的所有修复都建立在"新结点红、问题局部化"这个设计上。
</details>

**13.4-3** 删除时若 $x$ 与 $x.p$ 都红，RB-DELETE-FIXUP 能恢复性质 4。
<details>
<summary>答案</summary>
$x$ 双黑时 $x.p$ 必黑（否则 $x$ 侧与 $w$ 侧黑数矛盾，见 Case 1 论证）；$x.p$ 红只可能出现在 $x$ 为红黑（额外黑 + 红）时，即 Case 2 由 Case 1 转入的终止形态——循环退出后第 44 行涂黑即修复。
</details>

**13-3a**（Prob 13-3，★）AVL 树高度 $O(\lg n)$。
<details>
<summary>答案</summary>
设 $N(h)$ = 高度 $h$ 的 AVL 最少结点数。要高度 $h$ 必有一子树高 $h-1$、另一至少 $h-2$：$N(h) = N(h-1)+N(h-2)+1 \ge F_h$（斐波那契）。$F_h$ 指数增长 ⇒ $h = O(\lg n)$。
</details>

**模拟 13-M1**（★★）一棵红黑树黑高度为 3，最少/最多几个内部结点？
<details>
<summary>答案</summary>
引理 13.1：至少 $2^3-1 = 7$；至多：全黑路径之外尽量塞红——每层黑结点间可插红，$n \le 2^{2\cdot3}-1 = 63$（高度上界 $2\cdot3=6$ 的满红黑树）。一般地：$2^{k}-1 \le n \le 2^{2k}-1$。
</details>

**模拟 13-M2**（★★★）设计：为什么删除修复最多 3 次旋转，插入最多 2 次？旋转次数的界对工程意味着什么？
<details>
<summary>答案</summary>
插入：旋转只出现在 Case 2（1 次）+ Case 3（1 次），之后必终止 ⇒ $\le 2$。删除：Case 1（1 次）+ 之后 Case 3（1 次）+ Case 4（1 次），Case 2 不旋转 ⇒ $\le 3$。工程含义：单次写操作的指针改写量有硬上界——对并发/缓存失效/写放大（flash）友好，这是红黑树成为 Linux CFS、epoll、Java TreeMap 底层的重要原因之一。
</details>
